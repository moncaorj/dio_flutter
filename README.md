📌 Sobre o Projeto

Este projeto faz parte da Formação Flutter da DIO, com o objetivo de aprender e praticar o desenvolvimento de aplicativos utilizando Flutter e Dart.

Durante o desenvolvimento, são explorados conceitos fundamentais da criação de interfaces, estruturação de widgets, estilização e interação com o usuário.

🚀 Tecnologias Utilizadas
Flutter: Framework para desenvolvimento multiplataforma.
Dart: Linguagem de programação utilizada pelo Flutter.
Visual Studio Code: Ambiente de desenvolvimento.
Git e GitHub: Controle de versão e hospedagem do código-fonte.

🎯 Funcionalidades e Aprendizados
Criação de interfaces utilizando Widgets.
Utilização dos componentes Text, Column e Row.
Personalização de fontes, cores e tamanhos de textos.
Utilização de variáveis e interpolação de strings.
Implementação de interação com botões.
Atualização de informações na tela utilizando setState().
Execução e testes da aplicação no navegador Google Chrome.
Utilização de Hot Reload durante o desenvolvimento.

🖥️ Executando o Projeto
Pré-requisitos
Flutter SDK instalado.
Dart SDK.
Visual Studio Code.
Google Chrome.
Como executar
Clone este repositório:
bash
git clone https://github.com/moncaorj/dio_flutter.git

Entre na pasta do projeto:
bash
cd dio_flutter

Instale as dependências:
bash
flutter pub get

Execute a aplicação no Chrome:
bash
flutter run -d chrome
